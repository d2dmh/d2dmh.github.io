# Personal research website

个人科研主页，使用 GitHub Pages 发布。当前文字为待填写占位内容，并不代表真实论文、奖项或履历。肖像由网站所有者提供。

## 更新内容

- 修改 `content.js`，提交并推送到 `main`，GitHub Pages 自动更新。
- 本地打开 `index.html` 可使用“编辑内容”。线上访问 `/?edit=1` 也可打开同一前端编辑器，导出新的 `content.js` 后提交到仓库。
- 编辑器保存的是当前浏览器的本地草稿，并不能直接修改线上文件；它不是服务器管理后台，也不包含认证或 GitHub 访问令牌。
- 普通访客页面默认不显示编辑按钮。
